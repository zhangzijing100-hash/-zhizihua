# 抓包拆解报告 —— 龙族：卡塞尔之门（九游 2.0.9）

目标：不靠本地文件，直接从网络流量里取出「每个伙伴的命轮 / 碎片库存」。

**结论先说：抓到了，协议不是 TLS，但服务器回来的数据是全程强加密的，拆不下去。**

---

## 1. 怎么抓的（免 root）

手机没 root，但 Android 允许 App 用 `VpnService` 把整机流量导进自己进程。
用 [PCAPdroid](https://github.com/emanuele-f/PCAPdroid)（开源、免 root）抓成 pcap：

```powershell
adb shell appops set com.emanuelef.remote_capture ACTIVATE_VPN allow
adb shell am start -e action start -e pcap_dump_mode pcap_file `
  -e pcap_name /sdcard/Download/PCAPdroid/dump.pcap `
  -n com.emanuelef.remote_capture/.activities.CaptureCtrl
# …玩游戏…
adb shell am start -e action stop -n com.emanuelef.remote_capture/.activities.CaptureCtrl
```

抓了 107 秒（从启动游戏前的登录开始），1304 个包，0.81 MB。

## 3. 帧结构（已部分拆开）

**发送方一条消息一次 `write()`**，所以 TCP 段边界 ≈ 消息边界。客户端方向 116 段：

```

 0    34   3a 20 00 00      握手①：2 字节 + 8 个 int32（0 / -1 交替）

 2   664   67 82 95 26      登录包 —— 明文！
 3    23   9f 3e 0e 75 …
 4    13   ac 45 2d 64 …
 5     6   b4 f0 9a dd f2 7a
 6    42   38 d4 70 84 …
 …
21+  22    de 32 70 36 …    心跳：全是 22 字节，每秒一条，头每次都随机
```

## 4. 熵检验 —— 决定性的那一步

```
方向            整体熵      分块熵(12块)
客户端→服务器    7.647      6.43 5.70 4.64 4.78 6.85 6.97 7.01 6.96 7.07 6.98 6.94 6.98
服务器→客户端    7.999      7.99 7.99 7.99 7.99 7.99 7.99 7.99 7.99 7.99 7.99 7.99 7.99
                            （最长连续合法 protobuf 字段游程 = 1）
```

- **客户端→服务器**：开头几块熵只有 4.6–5.7（明文），后面升到 ~7.0（转加密）。
  符合「登录包明文 → 之后用会话密钥加密」。
- **服务器→客户端**：每一块都是 **7.999 bits/byte**，就是「完全随机」。
  连 protobuf 的结构痕迹都没有 → **全程加密，一处明文都没有。**

所以库存数据一定在服务器回来的那些密文里，但**看不到**。

## 5. 为什么停在这里

想解开，需要逆 `acoral`（这个游戏自研的网络层，`lua.cat` 里出现 1490 次）的：

1. **加解密算法** —— 客户端二进制里有 AES / RC4 / ChaCha 痕迹
2. **密钥怎么来的** —— 这是生死线：
   - 若密钥是**静态的**，或由可见的登录令牌派生 → 能离线复现，能解
   - 若是**握手时 ECDH 协商的临时密钥** → 只存在客户端内存里，
     **离线永远解不开**。要拿只能在客户端里跑代码（Frida），而 Frida 需要 root —— 这台机器没有。

那 150 字节对 150 字节的握手（#1），很像密钥交换。

**风险**：`libUE4.so` 是**未 strip** 的（203 MB、439,383 个动态符号），找到加解密函数不难；
但「是不是 ECDH」这个坎，可能要逆到一半才知道，且即使顺利也是**以天计**的工作量。

## 6. 顺带排除掉的

| 方向 | 结果 |
|---|---|
| 游戏日志里的背包数据 | `bag` 8524 处全是 **GarbageCollection**（假命中）；`Bag` 是 UI 面板名（`PanelBag` / `FortuneStarBagPanel`），只有创建事件，没内容 |
| `entry_info` / `module_info` / `skill_level_map` / `SyncItemChange` | 日志里 **0 处** |
| 游戏自己生成的分享图 `userdata/sharecache/*.png` | 只是宣传画（`流年携客归`），不含玩家数据 |
| `coscache` 30 个缓存文件（解压 24 MB） | UE4 配置资源（`partner_name: id=220000xxx`），静态游戏数据 |

## 7. 工具

| 文件 | 作用 |
|---|---|
| `game-dump/pcapscan.mjs` | 拆 pcap：列流 + 按首字节判别协议（TLS / HTTP / 自定义） |
