## 二、普通盘（创始 / 物质 / 执行）—— 规则成立

```
命轮值 = R5( Σbase × m(n) )
```

- `base`：UR 100 / SSR 30 / SR 20 / R 10
- `n` = 盘的成员数
- `m(n)`：n=1 → 1，n=2 → 5/4，n=3 → 4/3，n=4 → 17/12，n=5 → 3/2
- `R5` = **银行家舍入**（四舍六入五取偶）到 5 的倍数

|---|---|---|
| 四舍五入（.5 上） | 287 | 91.11% |
| 向下取整 | 283 | 89.84% |
| 向上取整 | 268 | 85.08% |

### 各分支系数验证（纯同稀有度盘，精确无歧义）

## 三、宿命之轮（170 个）—— 完全是另一套公式

`m(n)` 规则对宿命之轮 **0% 命中**。实测公式：

```
命轮值 = M(n) × ( Σbase / 10 + t )
M(n) = 10, 12, 13, 14, 15   (n = 1..5)
```

**验证：v 能被 M(n) 整除 —— 170 / 170 = 100%** ✅

等价形式：`v = (n+10)/10 × (Σbase + 10t)`

`t` 的取值随成员稀有度构成上升（n=5 时 t 从 3 到 6；全 SSR 盘 t 最大），
且**同一构成可能出现不同 t**，说明该表仍有未解出的成分（疑似与成员个体或另一隐藏维度有关）。

对照普通盘：宿命之轮的乘数 `(n+10)/10 = 1.1 / 1.2 / 1.3 / 1.4 / 1.5`，
与普通盘 `m(n) = 1 / 1.25 / 4/3 / 17/12 / 3/2` 不同，只有 n=5 时重合。
